
# File Uploader

File uploader is a web application where users can store files, organize them into folders and delete them. The project is built with Express, EJS templates, PostgreSQL, express-validator, Passport, bcryptjs, Prisma ORM and multer middleware as part of The Odin Project.

## Overview

Users can:

- Create a new account
- Log in and log out
- Upload and delete files in home page
- Create and delete folders
- Upload and delete files inside folder
- All Information is saved in the database
